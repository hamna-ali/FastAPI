# Task Manager API

A RESTful API built with FastAPI for managing tasks with full CRUD operations, featuring automatic documentation and JSON file persistence.

## 🎯 Overview

This project provides a simple yet powerful task management API that allows users to create, read, update, and delete tasks. Built with FastAPI, it offers automatic API documentation and high performance for task management operations.

## ✨ Features

- **Full CRUD Operations** - Create, read, update, delete tasks
- **Automatic API Documentation** - Interactive Swagger UI and ReDoc
- **JSON File Persistence** - Tasks stored in local JSON database
- **Pydantic Validation** - Automatic request/response validation
- **FastAPI Performance** - High-speed async API framework
- **Type Hints** - Full Python typing support

## 🛠 Technologies

- **FastAPI** - Modern, fast web framework for building APIs
- **Pydantic** - Data validation and settings management
- **Python 3.9+** - Programming language
- **Uvicorn** - Lightning-fast ASGI server

## 📋 Requirements

pip install "fastapi[standard]"
pip install uvicorn
